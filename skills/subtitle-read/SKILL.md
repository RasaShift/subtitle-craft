# 审稿

> **这份技能只当目录**：什么时候用、按什么顺序干、去哪查判据。判据条文与具体命令一律不在这里。
> 文中 `docs/…` 都指**当前项目库**的 docs。项目里没有这几份文件，就说明它不是字幕库——先问，别硬套。

## 什么时候用

清稿与对稿都过了，要判「观众会不会理解错」时。这是主线，读的是这一集的中文。

开头还有两件事属于本工序：**开工准备**（查前情回顾段边界、把一集切成两片、备料）和**定档**。

## 我吃什么、吐什么

- 吃：清稿后的字幕 + 英文参照 + 词表 + 对稿候选数（定档要用）
- 吐：`定档.md`（三行）+ 候选清单 + findings + 简报

## 按什么顺序

1. **开工准备**：查前情回顾段从哪结束、把一集切成两片（一片判、一片留）、备齐要喂给执行方的料、写明产物落哪。
2. **定档——岔路口，先定再读**：这一集读多深？`全量`（逐条读中文）还是 `关键点`（只核四条）。写进 `定档.md`，后面所有活按这个档走。
3. **按档读**：
   - `全量`：逐条读中文，读不懂才回头查英文。
   - `关键点`：只核 **否定词 / 数字 / 既成事实 / 人物关系** 四条，不顺手全读。
4. **只报「观众会理解错」的**。看不懂但意思没偏，不报；措辞难看但读者读得懂，不报。
5. **品控**：格式校验 → 预筛去重 → 抽看误报 → 漏报盲测 → 分档 → 越界校验。
6. **落盘并验收**：写进成品，再验一遍。
7. **写 findings + 判定表 + 简报**（格式见 `docs/findings写法.md`）。

## 我得自己记住的三条

1. **定档是岔路口**。档位错了，后面读得再细也是白读——关键点档被当成全量档读，等于多花三倍时间还没读对重点。
2. **关键点档只核那四条**，顺手全读等于没定档。
3. **抽到 0 条不等于质量好**。可能是抽样没抽到，也可能是不敢报——两种都要报给统筹方。
