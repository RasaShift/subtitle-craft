# 接活单

> **开工前问清八件事。只问不判** —— 判据一律在工序文档（`docs/工序-*.md`，带 `--with-skills` 才有），这里一条不抄。
> **八问全是剧级属性：一部剧问一次，集级不重问**（2026-11-08 改）。答案落**剧级一份**（剧库 `接活_本剧.md` 这类），集级只记一行档位；落 `定档.md` + 派活单是集级那一层的事。
> 上限 50 行（**稳定型**：八问固定，不随集数增长。实测 46 = 八问表 + 五节说明；50 是留给「以后加一问」的位置，满了删，不许拆）。

## 八问

| # | 问 | 为什么要问 | 答案影响 |
|---|---|---|---|
| 1 | 这字幕哪来的？机翻 / 字幕组 / 自制 / 不知道 | 定档的第一条信号就是「来源先验」，机翻直接全量、不抽样 | 定档 |
| 2 | 有人校对过吗？谁校的？ | 同上——「有人校过」和「翻译自己顺手过一遍」差很远 | 定档 |
| 3 | 手上还有什么？英文原轨 / 外挂字幕 / 另一版译稿 / 片源文件 | 没有参照轨，对稿判不了 T1「漏译」，那个 0 不代表没漏 | 走哪条链 |
| 4 | 做完给谁看？自己看 / 发给别人 / 发布存档 | 决定读多深、要不要补行、术语严到什么程度 | 定档 + 落盘 |
| 5 | 要做到什么程度？能看懂就行 / 尽量准 / 一个字都不许错 | 同上。可追问一句「有没有你最不满意的段落」——抽样往那儿多放 | 定档 |
| 6 | 有什么不能动的？人名、术语、歌名、某种说法 | 不问就改，改完不认账；这类只在清单里报、不动手 | 派活单禁区 |
| 7 | 有既定译名表或术语表吗？在哪？ | 有就照抄，没有就得从中文实文里反查，不能照英文字面编 | 第 5 步词表 |
| 8 | 交付要什么形态？单语还是双语、ass 还是 srt、覆盖原文件还是另存 | 「覆盖」不可逆；「另存」才能回头比 | 第 6 步样式 + 落盘 |

## 问不到怎么办

- **来源不知道** → 写「不明」。判据里只有「来源好或不明 **且** 抽 40 条 0 硬伤」才走关键点档，其余全量
- **目的不说** → 按最保守的「发布」算：全量、术语统一、该补的行补
- **不能动的没说** → 不改既有译名，只在清单里报「两种译法，待定」
- **手上有几份说不清** → 别猜，让他把目录给你看

## 答案落哪

| 答案 | 剧级（一份，全剧继承） | 集级 |
|---|---|---|
| 1、2、4、5 | 剧级答案表，一列一问 | `定档.md` 只记「承接剧级 + 本集档位」 |
| 3、8 | 同上 | 派活单「输入」节照抄 |
| 6、7 | 同上，7 还落 `词表.tsv` | 派活单「禁区」节 |

**为什么分两层**：八问是交付标准，不随集变。抄进 38 个文件就是复制 38 份，口径一改要回补 38 处（实测踩过）。

## 两条不许省

1. **问完才开工。** 不问就定档，等于替用户猜档位，猜错了整集白读。
2. **问了要落下来。** 只在对话里问过、没写进文件，下一棒看不见，等于没问。

## 集级不重问（2026-11-08 改）

**同一部剧从第二集起，八问一律不再问**——每集问一遍等于宣布「每集可能不同」，档位就从判据变成能随口拨的旋钮。
**只在这三种情况回头问**：① 交付对象变了（某一批单独发别人）；② 某集要单独提前交（试看集、样片）；③ 明确要求这集更严或更松。
**每集真正会变的是基线，不是八问**：条数、坏块、重叠、cps、话轮标记——那是量出来的，不是问出来的。
