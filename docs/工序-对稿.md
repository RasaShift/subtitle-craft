# 工序 · 对稿

> **这是哪一步**：四件工具里第 3 件（`tools/triage_diff.py`）的判据来源，也是「通用工序定义」的第一份。
> **管什么**：拿到「一条中文 + 一条参照」，判它该补、该改、还是不用动。
> **不绑什么**：不出现剧名、季号、集号规则。换一部剧，只要有一份中文轨、能配出对子，就能照做。

## 1. 这道工序解决什么

审稿能抓「意思翻反了」，抓不到「整句没译」；查表能抓「译名不统一」，抓不到「这句漏了半句」。
对稿专治第三种：**我方中文与参照对不上时，到底是缺、是错、还是只是说法不同。**

不做这一步的后果：所有差异被当成「都该改」，人力全耗在措辞噪声上；或者反过来一律「不改」，真漏真错整批放过。

## 2. 输入

| 输入 | 必需 | 干什么 |
|---|---|---|
| 中文轨（骨架） | 是 | 被判断的对象；一条不动、不拆不并 |
| 配对表（中文条 ↔ 参照条） | 是 | 证明「这一条该跟哪一条比」；由对齐器产出 |
| 参照轨（另一份同语种字幕 / 原文） | **否** | 只有它能判 T1「漏译」 |
| 词表（专名 / 术语） | **否** | 只有它能判「术语是否按词表译」；没给就明说这条没跑，别当成没问题 |

**参照不是必需的**——这是本工序的设计前提。理由：多数人手上只有一份字幕，要求先凑齐第二份，门槛高到没人用。没有参照就跑降级模式，见第 5 节。

**开工前先跑清稿**（`docs/工序-清稿.md`）：贴字、粘连和残留标签没清，本工序的假红会成倍——脏输入的错会被当成译文差异报上来。

**清稿改过中文，就必须重建配对表。** 配对表里存着中文原文，清稿一落盘它就过期了；而本工序只读表、不读字幕（`triage_diff.py` 只认「中文条号 / 中文文本 / 英文文本」三列），照旧文本出的候选，落地时锚点必然失配——不是改错，是白跑一轮。这是硬步骤，不是提醒。

## 3. 判断路径（两问，顺序固定）

```
一条对子
  ├─ 问一：参照这句的信息，我方中文有没有？
  │     ├─ 没有 ────────────────→ T1 漏译（补一行）
  │     └─ 有 ──→ 问二：意思对不对？
  │                 ├─ 不对 ────→ T2 误译（改这一行）
  │                 └─ 对 ──────→ T3 表述差异（不改，只登记）
  └─ 问不了（无参照 / 两边都通顺无仲裁者）→ T? 无法判定（不进分母）
```

**判序不许跳**：先问「有没有」，再问「对不对」。反过来会把整句缺失判成误译，补行就变成改行，位置也丢了。

## 4. 四类结论与边界

| 代号 | 正式名 | 英文 | 定义 | 动作 |
|---|---|---|---|---|
| **T1** | 漏译 | omission | 参照有这条信息，我方中文整句没有 | 补一行 |
| **T2** | 误译 | mistranslation | 我方有对应中文，但信息与参照不符 | 改这一行 |
| **T3** | 表述差异 | variant | 信息一致，只是说法或断句不同 | 不改，只登记 |
| **T?** | 无法判定 | undetermined | 判不了，不是判了不改 | 标注，交人 |

**互斥且穷尽**：每条对子必须且只能落进 T1 / T2 / T3 / T?。落不进去 = 判据有洞，补判据，不许自创第五档。

**不算 T1 的**（这些不是漏译，判了就是假红）：

- SDH 音效（`[门砰地关上]`）
- 背景歌词（参照标 ♪）
- 片头片尾落款、制作组署名
- 语气词（`Mm.` `Aah!`），且中文别处已表达同一语气

**不算 T2 的**：

- 断句、分段不同（我方三行对参照一句）
- 参照方自己听错写的错句——那是参照的问题，不是我们的
- 纯风格偏好（「他说」vs「他说道」）

**`DR0` 参照侧空有两种，处置相反（2026-11-08 加）**：真缺英文 → 逐条看；底本把一句英文拆成「首条带英文 + 中文续条」→ **整类不判**。判别靠一次统计，不靠逐条看：侧空条里，上溯最近带英文条、且该条英文本身多行（`\N`）的占比，**≥95% 判结构、<80% 判真缺**（剧库两季实测：这类占候选 42%，一条都不用改）。

**`DR1` 数字不一致有换算陷阱，只比数值不比单位**（2026-10-27 记）：

| 中文 / 参照 | 判定 | 为什么 |
|---|---|---|
| `60亿` / `six billion` | 对，别改 | 6 billion = 60 亿 |
| `三十五左右` / `mid 30s` | 对，别改 | 意译，不是数错 |
| `十斤` / `22 pounds` | **改** | 22 磅 ≈ 20 市斤，原译少一半 |
| `晚上 7 点到 10 点` / `A father of two` | **交回，不是数字错** | 中英说的不是一回事，疑似错行 |

**`DR1` 不判量级**（2026-11-08 加，剧库实测 9 处差 1000 倍、机器零报）：量级要另跑一份独立译本交叉核。英文 `£` 丢了会变成 `?`，**`?` 吞几位不固定**（同一集 `?5,000` 一处是 £45,000、一处是 £75,000），**禁止按「首位补 1」推**——一律查参照，参照也没有才落 `T?`。

**`DR2` 整条未译先看英文轨带不带独立英文样式**：带 → 英文直接上屏、观众看得到，**不改**；不带且是背景歌曲或字母串 → **不改**（不补译）；不带且是角色台词 → **真漏译，改**。

**`DR5` 术语不符要分清用的是哪张表**：同一 IP 多部剧各有自己的译名与警衔表，拿错表会整批假红（把人名判成译名错、把警衔判成术语错）。开工先确认这份表是哪部剧的、哪一季的。
**`DR5` 的匹配键只取人名、专有机构名、职衔全称**（2026-11-08 加）：普通名词换说法不构成理解错（`House→议会` 撞楼名、`Civil Service→公务员` 中文写「行政机关」、`Department→部门` 中文写「部里」），**这类归 `T3`**。**先看候选的规则分布**：某一条规则占九成时先怀疑匹配键，别逐条判——剧库 110 条候选里 105 条是 `DR5`，人判后只采纳 8 条。

**T3 要留记录**，不许「判了不改就不写」。下一个人要能看出这条已经被看过。

## 5. 哪些机器判、哪些必须人判

**明细在 `docs/工序-对稿-机判人判.md`**——分工表（逐条列了什么机器能挑、什么只能人看）、有参照/无参照各判得了什么、错位区间怎么划，都在那份里。

这里只留一句：**机器只挑嫌疑，一条都不定案**。T1 缺没缺、T2 对不对、T3 与 T2 的分界，全是人判。

**错位区间是人划的，不是机器产物**：某一整段中英整体错开时，逐条比只会把每条都报成误译。人给一张「起条号 / 止条号 / 理由」的表，对稿按它跳过、统计行报出跳过几条，审稿按它整段读。跳过 ≠ 没问题，这条要留在账上。

## 6. 输出

每条一行，字段固定（脚本落 TSV，语义由 `T1/T2/T3/T?` 承载）：

| 字段 | 内容 |
|---|---|
| `no`（工具列名 `中文条号`） / 时间码 | 中文轨原值，不改不动 |
| `old`（`中文文本`） | 中文原文，逐字照抄；抄错会让落地环节找不到位置 |
| 参照原文 | 没有参照就留空 |
| `verdict`（`建议代号`） | `T1` / `T2` / `T3` / `T?` |
| `rule`（`规则`） | `DR0`–`DR5` 之一，见 `docs/命名准则.md` 第三节 |
| `evidence`（`证据`） / 理由 | 证据只写能当场复算的：参照原文片段、词表 canon、出现次数；理由一句话 |
| `stage` | **工具输出，恒 `triage`**。三道的值各不相同（清稿 `mech` / 对稿 `triage` / 审稿 `read`），几张清单并成一张时靠它分清是谁判的 |
| `source` | 工具不输出，判案后由人补：改的是哪一份参照 |

统计固定报一行：`本集 T1 x 条 / T2 x 条 / T3 x 条 / T? x 条`。**收尾再跑一次交叉核**——「我中 vs 参照中」全库比一遍，只把不一致的挑成候选、不判对错，它是本工序的最后一步（方法见 `docs/工序-对稿-手册.md` 的「三条规则边界的查法」第 3 条）。

## 7. 与旧说法的映射（历史不丢）

旧说法对照：我们缺→`T1`、必看里判「改」的→`T2`、纯措辞/听写分歧/看错→`T3`、旧流程没有这一档→`T?`。**「看错」不是第四个出口**——它是 `T3` 的一种理由：字幕没错，是我方看错了。

**工序名也对过（2026-11-05 定）**：查表 → **清稿**、对轨 → **对稿**、通读 → **审稿**。老名字仍在别的库里用，两边是同义词，不是两件事。理由见判定记录「三道工序定名」。

## 8. 禁区

1. **判据只能由不干活的人定**。执行中发现判据有问题，写进简报，不许自己放宽。
2. **证据只写能当场复算的**。编造依据比漏报贵。
3. **不许为了数字好看调判据**。T1 都想压到 0，压的方法只有一个——把真漏也当成卡。
4. **改的人不验，验的人不改**。
5. 拿不准就落 `T?`。`T?` 不是失败，硬判才是。
