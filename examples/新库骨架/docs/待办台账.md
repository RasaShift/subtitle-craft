# 待办台账

> **给人看的清单，一眼答「现在该干什么」。** 每条一行，一行写不下的去详情。
> 详情（卡在哪、要动哪些文件、踩过的坑）→ `docs/待办台账-详情.md`；做完的 → `docs/archive/已完成_YYYYMM.md`。
> **编号是历史留下的身份证，不是顺序**——顺序看它在哪一档。这四档说的是「能不能动手」，不是做多深。

## 一、现在开

只开这一条线，其余一律标「暂不处理」。

- `#1` **待填**：一句话说清做什么，一行写完

## 二、等你拍板

我不自己定，你一句话就能动。没有这类事就把这一档删掉。

- `#2` **待填**：要谁定、定什么

## 三、开完接着上

有明确依赖的排这里，写清等谁。

- `#3` **待填**：等 `#1` 完了才动

- `#4` **待填**：为什么现在不动
