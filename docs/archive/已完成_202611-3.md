- **原假设被推翻**：「删了没人干错就不该存在」命中 **0 次**——17 份没有一份是为凑行数拆出去的（都没到上限），也没有一组同名标题该合（三套「硬约束」分别是切片 / 判读 / 品控三阶段的规矩）。真病是**引用失效**：`p4_*` 全库不存在却写在执行方必读主线、`工序-审稿.md` 行号指到空行、清稿手册指向的「审稿判据第二节」讲的是别的事、对稿-反例把自己的详版身份说成摘要。
