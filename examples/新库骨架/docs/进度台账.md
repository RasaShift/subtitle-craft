# 进度台账

> **本文件由 `tools/gen_progress.py` 从磁盘产物生成，禁止手改。**
> 改状态 = 改产物，然后重跑脚本。表里没有的，就是不存在的。
> **这份答「哪一集到哪一步」；`待办台账.md` 答「还有哪些活没干」。两件事，别混。**

## 怎么生成

```bash
python tools/gen_progress.py 03_工作区 --final 05_成品 --out 06_治理/进度台账.md
python tools/gen_progress.py 03_工作区 --stdout                     # 只看不写
python tools/gen_progress.py 03_工作区 --out 06_治理/进度台账.md --check   # 落后退 1
```

**它只认文件名，不认目录**：`X.base.ass → X.styled.ass → X.mech.ass → X.final.ass`，成品目录里的 `X.ass` 记「达档」。进度 = 能证明的最后一道工序；**判不出来的标 `⚠`，不许手补**。

## 为什么不让手填

人抄一次磁盘就多一份副本，而**落后不报错**，只会让人按旧状态排活——比报错贵。实测：某集换底本重做完，台账那行还写着「作废待重跑」；同一个「对稿候选数」在库里同时存在三个值。

**装不下的问题走卡点或判定记录**，别在表里加备注列。表里能填自由文本，它就会长成备注本。
