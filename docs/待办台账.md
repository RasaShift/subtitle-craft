# 待办台账

> **给人看的清单，一眼答「现在干什么、为什么还没干」。** 一行一条，四列填不满的去详情。  
> 详情（卡在哪、要动哪些文件、踩过的坑）→ `docs/待办台账-详情.md`；做完的 → `docs/archive/已完成_YYYYMM.md`。  
> **编号是历史留下的身份证，不是顺序**——顺序看「等什么」。  
> 2026-11-08 改形态：原「一档 / 二档 / 三档」用的是三把尺子（许可 / 目标 / 阻塞性），同一条能同时落进三档，于是「只开这一条线」永远兑现不了。改成「等什么」一列，理由见 `docs/判定记录.md`。
