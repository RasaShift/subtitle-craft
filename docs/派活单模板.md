## 2 · 本遍只看什么

### 第 1 遍 · 句法遍

**合上英文，把中文念一遍**，只在中文自己的层面判：

- 念不通、塌句、话说半截（以「的 / 时 / 就 / 但是」收尾，只有定语没主句）
- 指代悬空（「那个」「他」指谁看不出来）
- 问句译成陈述
- 断行错位（英文一句拆两行，中文把上一行重复一遍，或断在反义处）
- 话轮标记 `- ` 个数跟英文对不上——**数个数，不靠念**

七类形态逐条找（不带清单，出条数会差一个数量级）：

1. 英文一句拆两行时，中文第二行把上一行重复
2. 残句／半句话（以「时」「的」「就」收尾）
3. 漏主语宾语（英文有主语，中文只剩「那个」）
4. 问句译成陈述
5. 被打断的截断行（英文 `--` 或逗号挂空，断点划错位置）
6. 中文通顺但跟英文意思不符（本遍不主查，看到明显的照样报）
7. **话轮标记 `- ` 个数跟英文对不上——数个数，不靠念**（判据 `F7`；老库十集扫出 16 处，句法遍／逐词遍／复扫／盲测四轮全没抓到，就因为清单里没这条）

### 第 2 遍 · 逐词遍

第 0 步：先读英文整句，再读中文，只问「这两句说的是同一件事吗」。不是 → 直接报。
是 → 才核这三样，**不看中文顺不顺**：

1. **时态与语气**：`almost / about to / would have / could have / used to / until / still / already / no longer` → 中文落在「快 / 本来 / 差一点 / 到那时 / 还 / 已经」哪一档？
2. **关键名词**：中文换的那个词，指的是**同一个东西**吗？
3. **限定词与范围**：`good / bad / only / never / most / every / entire / all` 有没有落进中文？

> 这三类中文往往念着完全通顺，靠念一遍抓不到；两遍必须分开做，塞进同一次扫读会互相挤。

## 3 · 明确不报

措辞不够贴切 / 翻译腔 / 缺量词（不造成歧义）/ 语域与人物声音没到位（没丢成陈述句）/ 脏话净化。

一句话判据：**看不懂或会理解错 → 报；看得懂只是能更好 → 不报。**

## 4 · 禁区

- 只报不改：不动任何 `.ass` / `.tsv` 源文件
- 不碰 `05_参考资料/` 下任何文档，尤其台账
- 不写 findings、不跑 apply / verify
- 不读另一遍、另一片的产物（会互相锚定）
- 同一处只报一次

## 5 · 输出

写 `{{绝对路径}}\{{句法|逐词}}_片{{X}}.tsv`，**UTF-8 BOM + CRLF**，4 列，表头**原样照抄**：

**每一遍落自己的目录**（`{{遍}}/`），并表前不放进两边都看得见的目录——两遍互不可见是独立的前提，不是礼貌。

```
时间码	一句话理由	建议改法	严重度
```

- **时间码**原样抄输入
- **一句话理由**：问题在哪，不写长篇证据
- **建议改法 = 能整行替换的完整中文段**：整行中文原封不动抄下来，只动要动的地方。
  只写修好的那半句 = 不合格（续二 E01 实测：落盘方要花时间拼回整行）。
- **严重度**：`must` / `should` / `minor`
