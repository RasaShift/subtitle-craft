# archive · 归档区

放**不再改、但以后可能要查**的东西。跟现役文档分开，免得下次改东西时被它的旧口径带偏。

## 该放这儿的

- 被否决的方案（当初怎么想的、为什么否）
- 旧版工具或旧版工序（已被替代，但想留个对照）
- 一次性分析报告（跑完就没用了，但结论可能被引用）
- 某次事故的完整现场记录
- **判定记录的旧卷**（`判定记录_YYYYMM.md`）——这不是「被否决的东西」，是账本翻页。当前卷满 150 行整卷搬进来，`docs/判定记录.md` 的索引留一行指针。旧卷只读。

## 不放这儿的

- 还在用的文档 → `docs/`
- 跑批产生的数据表 → 各剧库的 `03_工作区/`（现役两个剧库是历史编号；**新库按 `examples/新剧接入.md` 建 `02_工作区 / 03_成品`**）
- 真实台词、术语表、成品 → **永不入库**

## 命名

`<主题>_<日期>.md`，例如 `对齐算法旧版_20261030.md`。
日期用写完那天，不用事发那天——查的人是按「什么时候定的」找。

## 挪进来的规矩

从 `docs/` 挪进来时，在原位置**留一行指针**（指向本目录里的文件），别直接删。
删了以后没人知道这件事被处理过，过一阵会被重新提出来。
