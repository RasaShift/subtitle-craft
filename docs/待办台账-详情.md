# 待办台账 · 详情

> `docs/待办台账.md` 的展开。**给人看的是那份，给 AI 看的是这份。**
> 每条写四样：**核于** / 是什么 / 卡在哪 / 要动哪些文件。编号与主表一一对应，主表删行这里就删段。
> **「核于」是第一行，写哪天核的、核了什么**（例：`核于 2026-11-07（核过：脚本在不在）`）。
> 没这一行，`doc_lint` 会报，下一个读的人也没法判断「卡在哪」还成不成立——
> 11-07 一天里三条写错（数字过期、顺序过期、指的文件不在本库），共同点就是没人记过核的日子。
> 只写日期不写核了什么，等于没写。
> 做完一条，主表删行 + 这里删段，`docs/archive/已完成_YYYYMM.md` 记一行。
> 顺序跟主表走（按「等什么」），不按编号。
