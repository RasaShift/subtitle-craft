## 一、命中项（十四项，先问有没有，再问对不对）

| 组 | 编号 | 判什么 |
|---|---|---|
| **C1 理解反** | 1.1 | 否定：`not / no / never / n't` 在不在、位置对不对 |
| | 1.2 | 动作方向：让／请／被／使／派／替 的施受反没反 |
| | 1.3 | 因果、条件、比较的方向 |
| | 1.4 | 时体：`did / sent / has / was` 是「已经」，不是「要／会」 |
| | 1.5 | 数字、金额、年代、人数：量级或单位对不上就算命中 |
| | 1.6 | 肯否落到两种读法都通 |
| **C2 看不懂** | 2.1 | 句子塌了：缺主谓宾、话说半截 |
| | 2.2 | 指代悬空：他／她／它／这／那 找不到对象或换人了 |
| | 2.3 | 术语错位：同一概念两种译法，或与词表冲突 |
| | 2.4 | 无中生有：译出英文没有的地点、数字、身份、动作 |

**优先级**：C1 > C3 > C2。**读完上面十四条之后**才适用这句：全不命中 → 不改；命中任一条 → 应改。没读就念这句，等于没判——闸在 `docs/工序-审稿.md` 完成标志⑤（`check_rules.py`）。

**关键点档只核四条**：`1.1` 否定、`1.5` 数字金额年代、`3.1` 既成事实、`3.3` 人物关系。选这四条的理由是「错了会让观众理解错剧情」，其余条目漏了只是不够好。

## 二、不报的十二类（判据的另一半，别只记命中项）

措辞不够贴切、翻译腔、文言腔、缺量词、具体译成笼统、反讽弱化但仍读得出态度、人物声音不像、语域略偏、中文搭配不当、的／得／地混用、脏话净化、单纯超长。

**这十二类报上去的后果不是「多改几条」，是「真问题被淹掉」**：老库实测一批 16 条复核意见里，4 条是抽样片段掐头去尾造成的假阳性。

**已知误报一处（不算新条目，是 `2.2` 的边界）**：片头「前情提要」那一行的**剧名被词表当成人名**，会触发译名类判据——剧名用的是固定译法，不是人名译法，**一律不报**（2026-10-26 定，每集各 1 行）。归在这里而不是加进十二类，是因为它的性质是「规则认错了对象」，不是「这类本来就不该报」。

## 三、七种形态（看到这些形状先怀疑，不代替条目）

第二行重复上一行、残句以「时／的／就」收尾、漏主宾只剩「那个」、问句译成陈述、被打断的截断行断点划错、中文通顺但意思不符、**话轮标记个数不够**。

最后这条单独记（本库编号 `F7`，引用写「审稿 F7」）：英文一行有多个 `- `，中文的 `- ` 必须跟上，**要数个数、不靠念**。老库十集扫出 16 处，句法遍、逐词遍、复扫、盲测四轮全没抓到——清单里没这一条，就没人看。

**F7 的适用条件（2026-11-08 加，`GQ-14`）：先量基线，再套本条。**
老剧的中文轨可能整套都不带 `- ` 标记（靠空格和语境分话轮），那是**底本风格，不是漏译**。机械补齐会把「一人连说两句」改成「两人对话」——那才是真让观众理解错。一部 538 条的剧实测：英文带双标记 79 条、中文带标记 0 条，机械套要改 79 条并撕裂全片风格。
**量两个数，再判**：① 英文里一行出现两个及以上 `- ` 的条数；② 中文里带 `- ` 的条数。**后者为 0 → 整份不带标记**，F7 降级为「**只在话轮丢失导致歧义时报**」，不要求逐条补齐。这种实例长这样：某条的中文整行被换成译者注，两个话轮的台词全丢（性质归 `C2.5`，仍要报）。
**不量就判等于没判**——「判据指了路必须同时设闸」对这条也适用：那两个数没量出来，不许对 F7 下任何结论。

**降级之后有出口（`GQ-28`）**：整份不带标记不等于「这条判完了」。**补不补由委托人定**（默认不补、照原底本风格走）；决定补的，按 `docs/中间产物格式.md` 的「话轮标记」一节逐条补——**记为格式层改动，不是审稿改动**，在 `定档.md` 里单列，验收按格式层那一栏报数，别混进审稿密度。

## 四、加条目的规矩

1. **编号沿用本库**（`C1.x` / `N` / `F`），不在这里自创前缀；编号单独出现时必须带归属（「审稿 F7」）。
2. **一条一行，写「判什么」不写「怎么改」**——改法归落地，不归判据。
3. **新条目先问「能不能被十二类吃掉」**：会被吃掉的说明它本来就该不报，别加。
4. **真实台词不进判据**：写进判据的那一集就不能再当回归集，反例一律用虚构句。
