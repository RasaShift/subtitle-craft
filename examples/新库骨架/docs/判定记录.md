# 判定记录

> 只写「定了什么 / 为什么 / 什么条件重开」，一条三行以内。**判过不做的也要记。**
> 过程在 `.workbuddy/memory/`，待办在 `docs/待办台账.md`，内容放哪看 `docs/文档落点表.md`。
>
> **这份是账本，不是文档——只装「索引 + 当前卷」。**
> 当前卷满 150 行，整卷搬进 `docs/archive/判定记录_YYYYMM.md`，索引留一行指针。**不设总量上限**。
> 同一件事前后定过两次的，看后一条。

**索引**（一行一条，只加不改；点卷名看结论与理由）

**{{日期}}**（1 条，见下方当前卷）
- 示例：一句话说清定了什么

## {{日期}}

### 示例：一条判定怎么写

- **结论**：定成了什么，具体到下一棒能照着做。
- **理由**：为什么这么定；不这么定会出什么事（有实测就写实测，没有就说没核实）。
- **重开条件**：出现什么情况要重新看这一条，别让它变成永远正确的旧结论。
