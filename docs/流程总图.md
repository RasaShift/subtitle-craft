# 流程总图

> **最后更新：2026-11-08** · **这张图只装两件事：步骤顺序，和步骤之间「谁产出、谁吃」。**
> 每一步怎么判，在 `docs/工序-*.md`；这里不抄判据，只画接口。

## 0. 一句话

**一份字幕从进来到能交，走十步：两步备料、一步攒料、三步清对、一步定档、一步审稿、一步落地、一步验收。**
**审稿读多深，由定档决定**——这是全流程唯一一个岔路口。

```
[料] 体检 → 对齐（可选）→ 攒词表（可选）+ 定样式基准（文件层必需）
[清] 清稿·文件层 → 清稿·文本层 → 清稿清单先落盘
[对] 对稿（有参照才做）→ 人判案
[定] 定档：来源先验 + 抽 40 条 + 对稿候选 → 全量 / 关键点
[审] 审稿（按档执行：全量逐条 或 只核关键点）
[落] 对稿定案 + 审稿清单 并成一张 → 落地（写回 + 复算）
[收] 验收：accept 一条命令把该对的数字报全，有 ✗ 就是退出码 1，停下来
```

**验收是正式的一步，也是第四道工序（2026-11-07 定），不是落地的附注。** 它自己吃三样（成品、两张清单、`定档.md`），自己吐一份过/不过的结论，过不了不许交付——所以它有独立判据文档、有自己的工具，不挂在第 8 步后面当尾巴。

**多集不按集排、按段排**（2026-11-08 加，判法在 `examples/新剧接入.md` 第 11 节）：能提前做的全前置，审稿单独按集放最后。四段 —— **0 预扫**（机改类工具全库跑一遍，只出清单不落盘）→ **1 落盘**（清稿 + 重建配对表 + 对稿定案，按季一批）→ **2 单集**（定档 + 审稿 + 落地 + 验收，一集一闭环）→ **3 收尾**（全剧一致性比对）。三条不许省：段 1 与段 2 **串行不交错**（上游词表与规则要到最后一集才收敛，抢跑会让已审完的集被后续变更波及）、段 0 **只扫不落盘**（一起落盘把回滚粒度从一季放大到全剧）、**抽样只报警不放行**（0 硬伤只许写「未发现硬伤」）。依据可算：审稿约 2.8h/集、不可重跑、占人力约 87%，前置段是机改、可重跑、占 3%。

## 1. 十步与接口

> **有判据文档的是工序**（清稿 / 对稿 / 审稿 / 验收，判据见 `docs/命名准则.md` 第四节），其余是不带判据文档的步骤——备料（造底本 · 体检 · 对齐 · 攒词表 · 定样式基准）与调度执行（定档 · 落地）。**顺序有个例外**：手上一份中英双语文件时，第 1 步直接跳过——配对表到第 5 步前一起出，那时文件层的 `--f6` 已把中英拆开。

| # | 步 | 干什么 | 吃什么 | 吐什么 | 谁吃它的产出 |
|---|---|---|---|---|---|
| 0 | 体检 | 摸清这份字幕能不能动 | 字幕文件 | `体检.tsv` | 人：坏块不为 0 就先修字幕，别往下走 |
| 1 | 对齐 | 中文当骨架，参照挂上去 | 中/英（或双语轨） | `X.align.tsv` | 对稿（唯一入口） |
| 2 | 攒词表 | 挑专名候选，人填译法 | 字幕 | `词表.tsv` | 清稿 MT1、对稿 `--term`、审稿（判术语） |
| 3 | 清稿·文件层 | 编码/画布/样式表/字号统一到基准 | 字幕 + **样式基准** | 统一后的字幕 | 文本层（拿它当对象） |
| 4 | 清稿·文本层 | 贴字、标签残留、译名错写 | 上一步的字幕 + 词表 | `X.mech.tsv` | 落地（先单独落一次） |
| 5 | 对稿 | 与参照对不上时，是缺、是错、还是说法不同 | `X.align.tsv` + 词表 | `X.triage.tsv`（T1/T2/T3/T?） | 人判案；**候选数还要喂定档** |
| 6 | 定档 | 判这部剧要不要全量审、审多深（定的是**审稿强度**，不是上映档期） | 来源 + 抽样 40 条 + 上一步候选数 | `定档.md`（来源/抽样/档位三行） | 审稿（决定读多少） |
| 7 | 审稿 | 字都对、话也通、意思偏了半格 | 清稿后的字幕 + 英文 + 词表 + 档位 | `X.read.tsv` | 落地（合并后） |
| 8 | 落地 | 按「条号+旧文本」写回，写完自己复算一遍 | 字幕 + 两张清单 | 成品 + 复算报告 | 验收 |
| 9 | 验收 | 该对的数字一次报全；有 ✗ 就停，别往下交付 | 成品 + 两张清单 + `定档.md` | 验收结论（过 / 不过，附各项数值） | 人：过了才算这一集完 |

## 2. 四条硬顺序，各有各的理由

| 顺序 | 理由 | 违反了会怎样 |
|---|---|---|
| 文件层 → 文本层 | 文件层重写整行但不动文本，跑完文本锚点仍有效 | 反过来做，样式器还得把文本原样保住再对一遍账 |
| 清稿 → 对稿 | 脏输入（粘连、贴字）会让对稿假红成倍 | 假信号淹掉真问题，人力全耗在噪声上 |
| 对稿 → 定档 → 审稿 | 定档要读干净文本（清稿后），要一个全量负证据（对稿候选数）；审稿要跳过错位行 | 清稿前抽样，会把「译名不统一」误读成「翻译差」，白读一批 |
| 清稿先落 → 其余并成一张再落 | 对稿要吃干净输入，所以清稿必须单独先落盘；落盘后不能再回头改清稿 | 后一行静默覆盖前一行，复算仍全绿（已实测，`land_verify` 直接拒，退出码 2） |

**「清稿一次、其余一次」是硬要求**：清稿单独落盘后，对稿定案的改动与审稿清单必须并成一张、落一次——落两次之间没有复算，错了看不出来；同一条在清单里只许出现一行。

## 4. 谁触发、谁定案

| 角色 | 管什么 |
|---|---|
| 统筹方 | 决定这一步跑不跑、什么时候跑；清稿、对稿、定档、审稿都由它触发 |
| 机器 | 只挑候选、只算数值、只做替换。一句判断都不下 |
| 人 | 定案。对稿的 `T?`、定档的档位、审稿的全部条目、词表的译法，都得人过 |

## 5. 一集跑完，命令长这样

> **都在本库根执行**，`01_源字幕` / `02_工作区` / `03_成品` 指剧库里的那一层，执行时把剧库路径带上（工具与剧库是两个根，别 `cd` 进剧库）。

```bash
python tools/subtitle_probe.py 01_源字幕 --tsv 02_工作区/体检.tsv
# 起点只有两份单语 SRT、还没有成品 ASS 的剧：先造底本（已有成品 ASS 的剧跳过这步）
python tools/build_base.py 01_源字幕/X.简.srt 01_源字幕/X.英.srt -o 02_工作区/X.base.ass --style-from 参照.ass
python tools/align_bilingual.py 01_源字幕/X.简.srt 01_源字幕/X.英.srt --tsv 02_工作区/X.align.tsv
python tools/term_candidates.py 01_源字幕 --min 2 --tsv 02_工作区/词表候选.tsv   # 人填成 词表.tsv
python tools/style_normalize.py check <字幕.ass> --video 1920x1080 --base 基准.ass
python tools/style_normalize.py apply <字幕.ass> --base 基准.ass -o 02_工作区/X.styled.ass
# 文本层：先扫（只做唯一改法），命中的出清单；挡住的进「需人判」表，人看过再自己加行
python tools/text_scan.py 02_工作区/X.styled.ass --term 词表.tsv --tsv 02_工作区/X.mech.tsv --report 02_工作区/X.需人判.tsv
python tools/land_verify.py apply  02_工作区/X.styled.ass 02_工作区/X.mech.tsv -o 02_工作区/X.mech.ass
# 清稿改过中文了 → 配对表必须重建一次（对稿只读表、不读字幕）：
python tools/bilingual_pairs.py 02_工作区/X.mech.ass --tsv 02_工作区/X.align2.tsv
python tools/triage_diff.py 02_工作区/X.align2.tsv --term 词表.tsv --offset 02_工作区/X.offset.tsv --tsv 02_工作区/X.triage.tsv
# 错位区间表是人划的（三列：起条号 / 止条号 / 理由）；没划就不给这个参数
# 定档：人读来源 + 抽 40 条（前/中/后各 13–14），看 X.triage.tsv 候选数，写 定档.md
# 审稿：无工具；档位=全量则逐条读，=关键点则只核否定/数字/既成事实/人物关系
# 落地：先并成一张，再一次写回（补行另给一张，位置按时间算）
python tools/land_verify.py apply  02_工作区/X.mech.ass 02_工作区/X.all.tsv --inserts 02_工作区/X.ins.tsv -o 03_成品/X.ass
python tools/land_verify.py verify 02_工作区/X.mech.ass 03_成品/X.ass 02_工作区/X.all.tsv --inserts 02_工作区/X.ins.tsv
# 验收：一条命令把该对的数字报全，有 ✗ 就退出码 1
python tools/accept.py 02_工作区/X.mech.ass 03_成品/X.ass --changes 02_工作区/X.all.tsv --inserts 02_工作区/X.ins.tsv --stage 02_工作区/定档.md
```

**补行表六列**：`start` / `end` / `cn` / `en` / `after_no` / `style`。位置由 `start` 算，`after_no` 填了就核对（对不上退出码 2）——老库 `after_ln` 只管位置不管时间，出过「19:31 后面跟着 19:06」的跳行。只支持 ASS。
