# 清稿

> **这份技能只当目录**：什么时候用、按什么顺序干、去哪查判据。判据条文与具体命令一律不在这里。
> 文中 `docs/…` 都指**当前项目库**的 docs。项目里没有这几份文件，就说明它不是字幕库——先问，别硬套。

## 什么时候用

拿到一份字幕，要把「改法唯一」的错清掉时。两类活：

- **文本层**：改每条字幕的中文字符串（贴字、标签残留、译名错写）
- **文件层**：改整份文件的结构与样式（编码 / BOM、画布坐标、样式表、字体字号、描边底纹）

**改法有二就不是清稿**——两种改法都通，退给对稿或审稿。

## 我吃什么、吐什么

- 吃：字幕文件 + 规则清单（**必需**）；词表、样式基准（可选，但**没有就凑不出唯一改法**）
- 吐：改动清单（TSV）→ 落地 → 复算；外加一张「需人判」清单，挑出来交给下游

## 按什么顺序

1. **先确认输入齐不齐**。文件层要动，先有样式基准；文本层要查译名，先有词表。没有基准就没有唯一改法，那不叫清稿，叫换成第五种面孔。
2. **文件层先，文本层后——顺序不许反**。文件层重写整行但不动文本，跑完文本锚点仍有效；反过来先改文本，样式器还得把文本原样保住再对一遍账。
3. **扫**。文件层用样式器按规则扫；文本层用扫描器，把命中分成「机改」和「需人判」两张清单。
4. **只改「机改」那张**。「需人判」整批交给下游，不在这里硬改。
5. **落地并复算**。实改数 = 声明数、跳过 0；同一条不许两段各声明一次。
6. **重扫归零**。同一批规则再扫一遍应命中为 0；不幂等的规则要写明为什么。
7. **落盘之后不许回头改**。对稿要在落盘后的文件上重跑，不许拿改前的清单接着用。

## 我得自己记住的三条

1. **文件层先于文本层**，反了要返工两遍。
2. **清稿必须先单独落盘**。落地后回头改，同一条字幕会被两段各声明一次——后一行覆盖前一行，而复算会显示全绿（踩过，见手册）。
3. **改法有二就不是清稿**。为了「一次全清」把判断类规则塞进来，等于偷偷放宽判据。
