# 通用库 · 长期事实

> **上限 3000 字符**（`doc_lint` 会喊）。只放「不看就会干错」的，其余进 `docs/`。
> **开工第一件事**：读 `docs/待办台账.md` 的「现在到哪」段——**状态只在那里**（本库没有接棒必读，11-09 解散）；导航看 `docs/文档落点表.md`。

## 这是什么

把「一个人带 AI 干长周期精工活」做成别人能照做的**工具 + 规程 + 模板**。**推 GitHub 是副产品，别为对外好看改内部设计。**

## 三个库

`字幕精校通用库`（本库，真身）／`是大臣系列`（实例，只读 + 写它 `03_工作区/`）／`日常杂活`（只读）。**别人的库一个字不改。**
**本库 = 维护方**（改工具 / 文档、判卡点，**不下场干活**）；**剧库 = 干活方**（照文档走、出成品、报卡点，**不许改本库**）。两库通消息只走 `docs/协作协议.md`，剧库不存副本。

## 对账

- 用户说「对账」= 读 `docs/协作协议.md` 第零节：读剧库 `卡点.tsv` + `待报通用库.md` → 判条目 → 改 §5 状态与顶部戳 → §8 记流水。**判据是时间戳，不是记忆。**
- 剧库报事实、本库判并写进 §5，**谁都不转述**。协议固定文件名，干活方不存副本。

## 四条常驻红线

- **不改别人的库**——本库会话不动剧库，只往剧库 `03_工作区/` 写产物；反过来开在剧库的会话改自己库不算违规
- 真实台词、术语表、成品**永不出门**
- 参数里不出现剧名、季号、集号规则；只用标准库
- 一件工具要在**至少两部剧**上跑过才算通用
- **机器只挑候选，人定案**——不许为了数字好看放宽规则；短台词真漏和栏目名，在机器眼里长得一模一样

## 不看不就会干错

- **四样**：工序定义 / 工具 / 骨架 / 4 份字幕技能，缺一样不算沉淀完。**件数看 `doc_lint` 的 `check_counts`**（跟 `tools/*.py` 实对，写错报 ERROR）；`selftest` 项数不写进文档。写死一个数就要几处同步，11-08 漂成过四个值。
- **跨库编号：一个问题一个号**（11-09 定）：`GQ-n` 只给剧库报本库的问题（新条目从 `GQ-19` 起）；**同一个问题两边沿用同一个号**，本库台账记它也用它；裸 `#n` 只给本库自己发现的；`#1`~`#12` 封存不改。
- **台账按「卡在谁身上」分节**：等我动手 / 等协作方 / 等外部 / 等你拍板。**别按内容分**（换库就失效）、别按进度分（同一条来回跳）。
- **名字按 `docs/命名准则.md`**；**集号真假看有没有剧名陪着**（`S01E01` 单独出现是假号）；**历史已定型**，只往前修。
- **指路必须同时设闸**——只写「注意」不加检查，整条路径能被绕开。
- **假报一次，闸就没人看了**：宁可漏报边界，也别给假 WARN。**同一个病根会复发**：修法照**语境**判，别只修单个检查。
- **改完文档跑 `eol_guard --fix`**：Edit 和 `write_text` 都会把整份文件写成 CRLF；新建文件按字节写。
- **4 份字幕技能**：`subtitle-clean`（清稿）/ `subtitle-align`（对稿）/ `subtitle-read`（审稿）/ `subtitle-check`（验收）。**全部 user-invoked——不在技能清单里，说「审这一集」不会匹配，必须敲全名**（11-09 实测：新会话只看得见 model-invoked 的那几个）。全局 `~/.workbuddy/skills/subtitle-*` 是软链，落回本库同名目录；**改全局＝改库工作区，直接进 `git status`**。
- **验技能触发必须在场景里**：空目录里问「这条该不该改」必然不触发（测的是通用问答）。判据看**第一步有没有读 `SKILL.md`**，绕过技能直读 `docs/` 干对了也算没过。详见判定记录 11-09「技能不触发」。
- **改闸的退出码，先把调用方全跑一遍**：`eol_guard` 把「检查 0 个」改成退 2，而 `pre-commit` 逐文件跑，于是每个新增文件都被判红。返回值是给调用方看的。
- **改口径要全文 grep**：只改显眼处会前后打架，**半改比不改更糟**。不留 `.bak`，旧版用 `git show HEAD:<path>` 取。
- **判据要事前可判**：报告写的「100%」多是事后视角。
- **全局技能 4 个**（11-09）：`writing-for-agents`、`diagnosing-bugs`、`retro`、`domain-modeling`。前两个是上游原版只改 description、正文不动；后两个**整份原样拷入、一字未改未译**。全局一改四库同时生效；原库在 `电脑管家/.workbuddy/_research/`。
